From the first job posting to the final performance review

  This guide follows the current project screens and role handoffs. Use it as a rehearsal script:
 each step tells you where to go, what to enter, what to show, and how the next role continues

                                                       the process.

Keep the Applicant ID, Employee ID, outlet, schedule week, and payroll cutoff written down for the test records. Use one
test applicant and one test employee. For payroll, choose a saved attendance date inside the selected cutoff.

1. Create a job opening

Sign in as HR or General Manager. Go to Dashboard > Job Postings > Create New Job Posting.
1. Select an existing Job Title. If appropriate, choose Add a new job title... and enter it.
2. Enter Department, Location, Employment Type, Daily Rate, and Description. Save the posting.
3. Find the new posting. If it is inactive, choose Set Active. Edit changes posting details, Set Inactive hides an opening from
applicants, and Archive removes it from the active management list.
4. Return to the public home page and scroll to Open Positions. Search for the opening and open its details.
Say: "HR maintains the vacancies. The public careers page displays active openings that applicants can select."

2. Applicant account and job application

Start on the careers page. Select Apply for this Position on the opening, or use Sign In > Applicant > Create an applicant
account.

1. Create an applicant account with email, password, and requested profile information. Confirm the address through the
email message, then sign in as Applicant. If needed, use Resend confirmation email or Forgot password? on the sign-in
page.

2. Open the job application. Complete the six steps: Position, Personal, Education & Work, Skills, References, and
Documents. Applicant email comes from the signed-in account.

3. Complete the required personal and address information, school and education, skills, at least one character reference,
and one emergency contact. Work experience and certificates can be added where applicable.

4. Upload a resume or biodata and at least one supporting document. Give every uploaded file a Document title. Review
file previews, enter the applicant signature and declaration date, then select Submit Application.

5. On the confirmation screen, copy the Applicant ID. The system also attempts to email it. If email delivery fails, the saved
application and displayed ID are still available.

To track it: Applicant profile > Your applications > View application status. A standalone tracking route is also available
after applicant sign-in. Refresh Status reloads the list. Reuse answers opens a past application as a starting point, while
Start new form clears the answers. Review details and documents before submitting each new application.

3. Review the application and requirements

Sign in as HR. Go to Recruitment and open the submitted application with View Profile.

1. Review the applicant details and preview or download submitted documents. Select Start Review. The status becomes
Under Review.

2. Open HR Requirements Validation. Check the standard documents that were actually received. Use Edit Checklist to
add a custom requirement, then Add and Done.

3. Enter an HR note and select Save Requirements. Complete checklist means Under Review. Missing items result in
Missing Requirements.

4. To demonstrate resubmission, sign in as the Applicant, open the same application, select Upload missing requirements,
title the documents, and submit them. Sign back in as HR, inspect the added documents, and update the checklist.

5. HR can edit permitted applicant details and mark a screened application Not Qualified where its status permits. Archive
and Restore are available from Recruitment for records-management demonstration.

The employee registration queue is separate from recruitment applications. Do not use it for applicant hiring. It is for an
existing worker asking HR to activate an employee login.

4. Interview and hiring decision

HR schedules the interview. In Recruitment, open the eligible application and select Schedule Interview. Enter date, time,
location, and optional instructions, then Confirm Interview Schedule. The status becomes For Interview. Applicant tracking
can show interview details. The system attempts to send a status email. Use Update Interview to revise the details.

The General Manager decides. Sign in as General Manager, open Recruitment > For Interview, then Hiring Decision.
Enter Interview Feedback / Remarks and select Hire Applicant or Not Hired. Continue with Hire Applicant for the full demo.
The hiring handoff prepares a separate employee record and employee account setup. It does not convert the applicant
login into the employee login.

1. Open the hired application and review Employee Onboarding. The panel reports whether the employee account is ready,
whether a setup email was recorded, and whether the employee password is set.

2. Use Complete Employee Account Setup when setup is needed. Use Resend Setup Email or Resend Hired Status Email
when a message must be retried. These actions require working server credentials and email configuration.

3. The employee follows the setup link and signs in using the employee login email, choosing Employee at sign-in. HR can
then open Employees and record the new Employee ID and outlet.

5. Employee records and account registration

Employee Records. HR opens Employees, selects a Search field, types in Search employees, and applies column filters.
Clear all resets the search and filters. HR selects Add Employee and completes the basic employee record, including
position, department, outlet, status, and hire date. Shift assignments are created in Schedule, not in the current Add
Employee form.

User Accounts. HR opens User Accounts. Create Account prepares a login for a linked employee. Existing accounts can
be edited, activated or deactivated, and have their password updated through the account workflow. Sign-in email for an
account already linked to authentication is not editable in this screen. At least one active HR Admin must remain, and the
signed-in HR Admin cannot remove their own admin access.

Employee self-registration. On Sign In, choose Employee > Existing employee? Register your account. Enter full name,
Employee ID, an active Position from the list, assigned outlet, email, and password. Confirm the email. HR opens User
Accounts and selects Pending (count) to open Employee self-registration requests. Review position, employee ID, outlet,
and email, then choose Approve and activate or Reject. Approval links the request to a matching employee record or
creates one if no employee record exists. The employee signs in after email confirmation and HR approval.

Profiles. Employees use My Profile > Edit Profile, the Account and Personal tabs, Change Password, and My
Documents. On an employee record page, employees can edit only their own profile. HR and supervisors use Employee
Records to view profiles. Schedule details are now managed under Schedule.

6. Schedule, publish, confirm, and swap shifts

Supervisor drafts. Go to Schedule > Create Schedule. Choose Regular Schedule, select employees, outlet, and week,
then set shifts, rest days, and break duration. Save as Draft. For special coverage, choose Special Duty, provide a valid
shift and reason, then Save Special Duty. The duty shift's time range is derived from the shift selection.

Import options. Import Excel reads a workbook and saves schedule drafts. Import Image reads a schedule image using
OCR. Review the detected week, match each employee, correct shifts and rest days, then Save as Draft. HR still needs to
validate and publish imported drafts.

1. As HR, open Schedule, find a Draft, and select Validate & Publish. Multiple drafts can be selected for bulk publishing.

2. As Employee, open Schedule and choose Confirm or Decline on a Published schedule. The roster status updates. Use
Weekly Employee Schedule to choose a week and outlet, then Print or Download CSV.

3. To swap, the employee opens Schedule Swap Requests > Request a Swap, or uses Request Schedule Swap on the
weekly roster. Choose their schedule and day, a coworker schedule, then the coworker's day. A regular published or
confirmed schedule is required.

4. The requester and coworker may choose different days. The form previews the coworker's weekly shifts. At least one
selected day must be a work shift. Special-duty schedules are not eligible. Send Swap Request.

5. The receiving employee selects Accept or Reject. After acceptance, HR opens Schedule Swap Requests and selects
Confirm and swap shifts or Reject. Confirm applies the exchange to both schedules.

Current schedule swaps can be cross-day exchanges, including workday for rest day. Two rest days cannot be swapped
because it would not change either schedule. HR checks approved leave and overlapping scheduled duties before
applying the final swap.

7. Attendance and Daily Time Record

Go to Attendance Management. Employees open their own DTR through this menu. HR and supervisors use the
attendance management view according to role access.

1. Manual entry: HR selects Manual Entry, chooses employee and date, enters the actual punches, checks the calculated
hours and attendance measures, then saves. Use the break punch fields only when the break was recorded.

2. Biometric import: select Import Biometric Data > Upload Report File and choose an Excel, CSV, or TXT report. Inspect
the preview and click Import [number] Record(s). Check skipped rows for invalid dates, duplicates, or employees that could
not be matched.

3. Use date, employee, and status filters. Select View Attendance for an employee group, then open an individual daily
record to review punches, total hours, late minutes, undertime, overtime, and validation status.

4. A supervisor or HR can select Review on an eligible record. HR can choose Correct record, link the employee if needed,
update the punches, and Save Correction. One employee should have one linked attendance row per day.

5. Open View Employee DTR from the details when available, or open Attendance Management as the employee. Select
Month Covered and use Print DTR. The recent DTR print layout is landscape for the full monthly table.

8. Employee requests and approvals

Employee files a request. Go to Requests > New Request. Choose Leave, Overtime, or Undertime, fill in the dates/times
and reason, then Submit Request. Leave dates cannot be in the past. Check My Leave Credits and My Requests to follow
the request. Employees can cancel their own pending request.

Request    Information to enter
Leave      Active leave type, start and end dates, reason. Check remaining allowance first.

Overtime   Date or date range, start and end time, reason. Match the period to actual additional work for the payroll
           demo.

Undertime  Date, start and end time, reason.

1. Supervisor opens Requests > Pending Actions and reviews a Pending request. Add remarks and select Approve or
Disapprove.

2. HR opens Requests > Pending Actions or Supervisor Approved and selects Validate. Add HR remarks and choose
Validate & Approve or Reject.

3. Employee returns to My Requests and shows the new status. Approved overtime contributes to payroll only for eligible
time that overlaps attendance-recorded extra work.

The employee request ID is assigned by a database sequence shared across submissions, which prevents two
concurrent users from receiving the same displayed request ID. It is safe to submit again only after checking the request
list if the network reported an uncertain result.

Leave administration. HR opens Manage leave types to add, rename, describe, activate, or archive choices. Under
Employee Leave Balances, search for an employee, select Edit, and save the allowance. The default policy shown by the
project is five company-paid days shared across leave types. Pending requests reserve days, approved requests count as
used, and eligible unused days may be converted at year end.

9. Payroll from attendance to released payslip

HR prepares payroll. Go to Payroll > Payroll Rates to review configurable premium percentages and holiday dates. Select
Generate Payroll, choose Payroll Period and Cutoff, and optionally select a position or fallback daily rate.

2. Open View Payslip and review hours, earnings, deductions, and net pay. Monthly Hours compares saved attendance
with cutoff hours. Edit Payslip is for authorized corrections to a draft.

3. Manual Entry is a separate route for an authorized draft. Select employee, period, cutoff, earnings and deductions, then

4. HR selects Forward to Accounting. The payroll status becomes For Review.

5. Accounting opens Payroll, reviews the cutoff and payslips, then uses Release Salary or Release. In Review Payroll
Release check employees, attendance exceptions, and differences. Confirm Release when the review is clear.

6. The employee opens My Payslips > Released Payslip Records, selects View, and can Print Payslip. Open Uploaded File
appears when an external payslip file is attached.

Payroll uses attendance, eligible approved overtime or undertime, salary rates, and configured premiums. A release
review can report a difference between current attendance and saved payroll hours. Review the source and regenerate
or correct the draft before releasing when that happens.

10. Performance evaluation and recognition

HR sets the criteria. Open Evaluation > Manage Criteria. Review or add criteria, categories, weights, maximum scores,
and descriptions. Active criterion weights must total 100% before an evaluation can be created. Save Criteria.

1. HR selects Assign Evaluation. Choose an employee and supervisor, enter the period start and end, and optionally enter
a period label. Select Assign to Supervisor.

2. The assigned supervisor opens Evaluation > Pending Actions - Assigned Evaluations and selects Evaluate for the
assigned employee.

3. Enter scores for each active criterion and remarks. Review Projected Final Score and select Submit Evaluation. The
status changes from Draft to Submitted.

4. HR or the General Manager opens Evaluation, reviews the submitted result, and selects Approve. The status becomes
Approved.

5. The employee opens Evaluation to see their own evaluation. HR and the General Manager can select an evaluation
period in the recognition view to review top performers. An eligible employee may see a performance highlight on the
employee dashboard.

Say: "HR defines the weighted criteria. The supervisor scores the employee. The system calculates the weighted result,
then HR or the General Manager approves it."

11. Dashboards, notifications, and final reports

1. Open Dashboard for the current role. HR sees recruitment, employee and attendance indicators. The General Manager
sees management indicators and pending approvals. Supervisors see schedule and request items. Accounting sees
payroll for review and released payroll. Employees see their own schedule, attendance, requests, and payslip information.

2. HR and the General Manager can use HR Analytics. Change Outlet, Reporting month, and Year to inspect attendance,
performance, recruitment, leave, and hiring charts. Some chart rows in the repository are analytics sample data, so label
them as sample data during the defense.

3. Use the notification bell to display alerts and Mark all read. Work anniversary notifications depend on the scheduled
database job being configured.

4. As HR, General Manager, or Accounting, open Reports. Choose Report Type, Reporting Period, and Outlet if available.
Use Custom range for the dates in the demo.
